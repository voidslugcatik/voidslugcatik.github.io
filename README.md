# Сайт-визитка voidslugcat

## Как редактировать

### 1. Переводы и тексты
Откройте `script.js` и найдите объект `CONFIG.translations`. Там два языка: `en` и `ru`. Меняйте текст внутри.

### 2. Цвета фона при наведении
В `script.js` найдите `CONFIG.gradients`. Каждый ключ соответствует атрибуту `data-hover` у плитки. Меняйте градиенты.

### 3. Список ссылок (плитки)
В `script.js` массив `CONFIG.links`. Добавляйте, удаляйте или меняйте порядок плиток. Для каждой укажите:
- `className` – для стилей (должен совпадать с классом в CSS)
- `href` – ссылка
- `icon` – класс иконки Font Awesome
- `titleKey` – текст заголовка (можно просто текст, без перевода)
- `descKey` – ключ перевода для описания (должен быть в translations)
- `hover` – ключ в gradients

### 4. Основные цвета сайта
Откройте `style.css` и в блоке `:root` поменяйте CSS-переменные.

### 5. Удаление бейджей
Бейджи уже убраны. Если захотите вернуть – смотрите старую версию.

## Запуск
Просто откройте `index.html` в браузере.

## Файлы
- `index.html` – разметка
- `style.css` – все стили
- `script.js` – вся логика и конфигурация

Удачи!
